## Hands-On Exercise Summary

### Hands-On Exercise 1 – Printing Basics

### Objective:

Learn how to display text and perform basic arithmetic operations in Python.

### Key Activities

- Using ``"print()"`` to display text and personal information.
- Performing arithmetic operations such as addition``(+)``, floor division``(//)``and exponentiation``(**)``.
- Creating simple console outputs.




### Hands-On Exercise 2 – Variables, Data Types & User Input

### Objective: 

Learn how to work with variables, different data types, and user input.

### Practice Tasks

- Creating and updating variables.
- Collecting user input using the input() function.
- Converting between ``int``, ``float``, ``str``, and ``bool``.
- Building a Student Information Card Generator.


### Hands-On Exercise 3 – Arithmetic & Comparison Operators

### Objective: 

Apply arithmetic calculations and comparison operators to solve practical problems.

### Practice Tasks

- Building a Payroll Calculator for salary computation and bonus eligibility.
- Creating a Student Performance Evaluator to calculate averages and determine pass status.
- Developing an Inventory Management System for stock monitoring.
- Simulating banking and shopping scenarios using comparison operators.


### Hands-On Exercise 4A – Logical Operators

### Objective: 

Learn how to combine multiple conditions using logical operators.

### Practice Tasks

- Building a simple login authentication system.
- Determining scholarship eligibility.
- Monitoring server health using system conditions.
- Validating an e-commerce checkout process.


### Hands-On Exercise 4B – Assignment Operators

### Objective: 

Learn how to update values efficiently using assignment operators.

### Practice Tasks

- Building a Student Score Tracker.
- Creating a Digital Wallet Simulator.
- Developing an Inventory Management System.


### Hands-On Exercise 5A – Introduction to Strings

### Objective: 

Learn the fundamentals of working with text data in Python.

### Practice Tasks
- Creating customer and patient registration profiles.
- Building structured AI prompt templates.
- Displaying customer feedback and support messages.


### Hands-On Exercise 5B – String Formatting

### Objective: 

Learn how to format strings using ``f-strings`` and the ``.format()`` method.

### Practice Tasks

- Building a Student Report Card Generator.
- Developing a Payroll System with a 7.5% tax calculation.
- Creating an E-commerce Receipt Generator.
- Designing an Employee Profile Card.

### Hands-On Exercise 6A – String Operations & Built-in Methods

### Objective: 

Learn how to manipulate, clean, and analyse text using Python string methods.

### Practice Tasks
- Formatting patient records.
- Cleaning and analysing fraud logs.
- Creating a simple movie recommendation system.
- Using methods such as ``.strip()``, ``.find()``, ``.replace()`` and ``.split()``.


### Hands-On Exercise 6B – String Slicing

### Objective: 

Learn how to extract and manipulate text using indexing and slicing.

### Practice Tasks

- Creating a Bank Card Security Formatter.
- Developing a Customer Profile Processor.
